# 爱丽丝工作台 · UI 设计语言 v0.1

> 主人定调（2026-09-14）：「前端的 UI 设计可以参考优秀游戏的优秀 UI」。
> 本文是**落地判据**。原则 0 管着它：**炫是手段，看得懂才是目的**——任何妨碍可读性的装饰都不做。

## 1 · 借鉴什么（游戏的强项 → 工作台的落点）

| 游戏范式 | 转成工作台 |
|---|---|
| HUD（血条 / 资源 / 小地图） | **驾驶舱顶栏**：DSH 状态灯 + 节点计数 + 总线健康 |
| 单位选择面板（RTS） | **节点卡片**：状态环 + 能力标签 + 最近动作时间 |
| 战斗 / 事件日志 | **实时行为流**：等宽字体、时间戳、按类型着色、自动滚动但**可暂停** |
| 星图 / 生产链（Stellaris · Factorio） | 节点关系与消息流向（P2 再做；MVP 只做名册） |
| 小人状态可视（RimWorld） | 每个节点一色：在线青 / 忙碌琥珀 / 离线灰 / 故障品红 |
| 动效反馈 | 状态变化**脉冲一次**；新节点上线「弹入」；**不做常驻动画**（省 GPU + 不干扰阅读） |

## 2 · 视觉规范

| 项 | 值 |
|---|---|
| 底色 | `#0a0e14`（近黑蓝）→ 面板 `#12161f` → 悬浮 `#1a2030` |
| 强调色 | 青 `#00e5ff`（主 / 在线）· 琥珀 `#ffb300`（忙碌 / 警示）· 品红 `#ff2d95`（故障 / 高优）· 绿 `#3ddc84`（成功） |
| 文字 | 主 `#e6edf3` / 次 `#8b949e` / 弱 `#4d5866` |
| 字体 | 界面用系统 UI 字体；**数据 / ID / 时间戳一律等宽**（Cascadia Code / JetBrains Mono / monospace） |
| 纹理 | 极淡网格（opacity ≤ 0.04），仅用于区分面板层次 |
| 形状 | 圆角 6px · 边框 1px `#21262d` · **不用阴影**（用边框 + 亮度分层） |

## 3 · 三视图

1. **驾驶舱**（默认）：状态灯 / 节点名册 / 任务一句话流 / 一键恢复
2. **节点详情**（点开）：该节点事件流 + 消息发送入口
3. **实时行为流**（右侧常驻）：所有结构性动作按时间倒序

## 4 · 反模式（明确不做）

- 不做花哨入场动画（延迟 > 200ms 即干扰）
- 不做不可读的霓虹堆砌（强调色只用于**状态**与**关键数值**）
- 不用 emoji 做图标（用 CSS 图形 / 内联 SVG，保持工程感）
- 不做没有数据的装饰图表（空态就老实显示空态）

## 5 · 与规格的关系

- 本文件只定**表现层**；功能与判据以 `self-plugins/dsh-agent-cluster/docs/spec.md` §4.3 / §7 P1 为准。
- 实现偏差（如通知机制、轮询替代 watch）必须回写 spec，不得只活在代码里（§5.20 纪律）。
