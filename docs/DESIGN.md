# 爱丽丝工作台 · UI 设计语言 v0.2

> 主人定调（2026-09-14）：「前端的 UI 设计可以参考优秀游戏的优秀 UI」。
> 主人定调（2026-09-15）：「现在工作台字太多了，改成图形化界面，我偏好星图」。
> 本文是**落地判据**。原则 0 管着它：**炫是手段，看得懂才是目的**——任何妨碍可读性的装饰都不做。

## 1 · 借鉴什么（游戏的强项 → 工作台的落点）

| 游戏范式 | 转成工作台 | 状态 |
|---|---|---|
| **星图（Stellaris / 群星）** | **主视图**：节点=星、任务=卫星、消息=光弧；一眼看全局面 | ✅ v0.2 |
| 战术 HUD（小地图 / 资源条） | 顶栏：DSH 状态灯 + 节点计数 + 总线健康 | ✅ v0.1 |
| 战斗日志（滚动事件流） | **底部脉冲条**：一行刻度表示最近行为，点开才展开全文 | ✅ v0.2 |
| 单位选择面板（RTS） | 上下文面板：点谁看谁（节点详情 / 任务判据与执行过程） | ✅ v0.2 |
| 生产链（Factorio） | 任务在天体上的流向（派发 → 执行 → 回结果 → 验收） | 未做（U11） |
| 小人状态可视（RimWorld） | 每颗星一色：在线青 / 忙碌琥珀 / 离线灰 / 故障品红 | ✅ v0.1 |
| 动效反馈 | 状态变化**脉冲一次**；**不做常驻动画**（省 GPU + 不干扰阅读） | ✅ |

## 2 · 视觉规范

| 项 | 值 |
|---|---|
| 底色 | `#0a0e14`（近黑蓝）→ 面板 `#12161f` → 悬浮 `#1a2030` |
| 强调色 | 青 `#00e5ff`（主 / 在线）· 琥珀 `#ffb300`（忙碌 / 警示 / 待验证）· 品红 `#ff2d95`（故障 / 高优）· 绿 `#3ddc84`（成功） |
| 文字 | 主 `#e6edf3` / 次 `#8b949e` / 弱 `#4d5866` |
| 字体 | 界面用系统 UI 字体；**数据 / ID / 时间戳一律等宽**（Cascadia Code / JetBrains Mono / monospace） |
| 纹理 | 极淡网格（opacity ≤ 0.04），仅用于区分面板层次 |
| 形状 | 圆角 6px · 边框 1px `#21262d` · **不用阴影**（用边框 + 亮度分层） |

## 3 · 视图体系

1. **星图**（默认主视图）：天体空间里看全局面；点星/卫星 → 右侧上下文面板
2. **脉冲条**（底部常驻）：行为事件的图形化（刻度），点击展开完整事件流（原文）
3. **上下文面板**（右侧）：空选=概览（大数字 + 最近 3 条）；选中=节点详情 / 任务详情
4. **列表**（可切换的回退视图）：v0.1 的名册 + 任务一句话列表——星图看不清时用它，**已验证能力不因改版丢失**

## 4 · 星图语义（天体映射 · 全部字段来自总线，不许凭空）

| 天体 | 映射 | 数据源字段 |
|---|---|---|
| 中央恒星 | 主脑节点（`role` 含「主脑」；无则取最新在线的 `web` 节点） | `nodes/*.json` |
| 行星 | 每个其它节点 | `nodes/*.json` |
| 内环 / 外环 | 在线 / 离线 | `now - atMs < 30_000`（不变量 I2） |
| 星色 | 青=在线 · 琥珀=忙碌（近 20s 有行为事件）· 灰=离线 · 品红=有失败/阻塞任务 | `steps` · `actions` · `tasks.status` |
| 卫星 | 任务，绕其 `assignee` 星运行；无 `assignee` → 绕中央恒星 | `tasks/*.json` |
| 卫星色 | 青/琥珀=未收尾 · 绿=已完成 · 品红=失败；**琥珀环=有未验证项** | `tasks.status` · `unverifiedCount` |
| 光弧 | 消息（`from → to`；`owner` 解析为中央恒星），最近 8s 加亮一次 | `messages` |

**为什么不画力导向图**：力导向每帧都在动，星位不稳定 ⇒ 主人无法「认星」（哪颗是哪颗靠位置记忆），且违反「不做常驻动画」。故采用**确定性径向布局**：角度由 `hash(nodeId)` 决定，同一节点永远在同一角度。

## 5 · 文字纪律（本次改版的核心诉求）

> 主人的原话是「字太多了」。文字不是不能有，而是**必须退到第二层**。

1. 星图内文字**只有三类**：① 中央恒星名 ② **在线**星的短名（离线星不显示名字）③ 数量徽标（数字，不是列表）
2. 长文本（任务意图 / 判据 / 证据 / 事件正文）**只出现在右侧面板**，且必须**点选后**才出现
3. 行为流默认折叠成刻度条；**同时可见的正文不超过 3 行**
4. 空态不写解释性长句——空就是空

## 6 · 反模式（明确不做）

- 不做花哨入场动画（延迟 > 200ms 即干扰）
- 不做不可读的霓虹堆砌（强调色只用于**状态**与**关键数值**）
- 不用 emoji 做图标（用 CSS 图形 / 内联 SVG，保持工程感）
- 不做没有数据的装饰图表（空态就老实显示空态）
- **不做常驻动画**（脉冲只在「变化」时发生；忙碌星的心跳是状态而非装饰）
